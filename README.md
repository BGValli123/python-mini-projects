## 🌡️ Advanced Temperature Converter

A CLI-based Python application with multiple features:

### 🚀 Features

* Convert between Celsius, Fahrenheit, and Kelvin
* Tracks conversion history 📜
* Clear history option 🗑️
* Handles invalid inputs ⚠️
* Menu-driven interface 💻

### 💻 How to Run

```bash
cd temperature-converter
python main.py
```

### ▶️ Demo Output

```
=============================================
   🌡️ Advanced Temperature Converter
=============================================

Choose conversion:
1. Celsius → Fahrenheit
2. Fahrenheit → Celsius
3. Celsius → Kelvin
4. Kelvin → Celsius
5. View History
6. Clear History
7. Exit

Enter choice (1-7): 4
Enter temperature: 12

========================================
✅ Result: 12.0K → -261.15°C
========================================
```

## 🔤 String Reversal Program

A Python program that demonstrates multiple ways to reverse a string.

### 🚀 Features

* Reverse string using slicing
* Reverse using loop logic
* Reverse using `reversed()` function
* Reverse using while loop
* Clean and structured output

### 💻 How to Run

```bash
python string_reverse.py
```
